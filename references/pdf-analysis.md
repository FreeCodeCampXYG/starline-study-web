# PDF 分析与定位规则

## 提取顺序

1. 读取页数、元数据与逐页文字层，定位格式统一为 `page N`。
2. 对无文字层或文字明显过少的页面设置 `needs_visual_review: true`。
3. 图片型课件必须使用 PDF 页面渲染器合成背景、透明层、文字层和小图层。禁止仅凭尺寸或字节数选择一张内嵌图片冒充整页；无法渲染时记录限制并停止视觉结论。
4. OCR 或视觉识别结果必须与页图核验。模糊字、二维码内容和无法确认的专名标记 `待验证`。

## 标签协议

- 书级标签：主题、适用角色、关键能力、使用场景。
- 章节标签：每章 2–4 个稳定概念词，避免同义词泛滥。
- 页级标签：每页 2–6 个，至少包含章节与优先级。
- 优先级标签：`核心20%`、`支撑80%`；可追加 `行动项`、`案例`、`待验证`。

网页中的标题、摘要、批注和原页预览必须共享同一个页码主键。搜索结果点击后直接打开对应页，不允许只跳到模糊章节。

## 80/20 批注

- 核心页约占总页数 15%–25%，优先选择总模型、关键转折、方法闭环和可执行检查表。
- 批注回答“这页改变什么判断或行动”，不重复标题。
- 支撑页保留简短定位说明；信息不足时标为 `待验证`。

## 压缩 PDF 与书签

- 压缩前读取原 PDF outline；压缩后不能只比较文件大小和页数。
- 若压缩工具保留 outline，验证章节标题及目标页；若采用图片重建 PDF，按学习笔记章节起始页重建书签。
- 书签页码采用 1 基编号写入配置，脚本转换为 PDF 内部 0 基索引。
- 使用 `scripts/add_pdf_bookmarks.py input.pdf bookmarks.json --output output.pdf` 添加书签；输出不得覆盖输入文件。
- 最终至少验证书签数量、顺序、标题和首尾目标页。
