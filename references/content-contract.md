# 内容与视觉契约

## 学习结构

网页顺序由 `experience-brief.md` 的首要任务决定，不再默认套用 Hero → 卡片网格。常见学习页可从以下模块中按任务选取并排序：

1. 快速开始：主题、首要任务、来源范围和关键证据限制；
2. 快速掌握：3–7 条关键收获；
3. 知识地图：章节关系或学习路径；
4. 核心章节：结论、解释、关键点、例子、视觉、来源；
5. 易错点/争议：常见误解与来源冲突；
6. 术语表；
7. 主动回忆题；
8. 行动清单；
9. 来源表。

学习页默认还要把这些模块串成闭环，而不是散落在页尾：2 分钟核心线、默认隐藏答案的主动回忆、面向具体对象的复述、一个真实迁移动作和可调整的间隔复习。具体规则见 [学习方法契约](learning-science-contract.md)。

若页面将通过 GitHub Pages 或其他公开站点分发，启用本文件的“署名、正版引导与权利边界”；可在来源表前后增加“支持正版”和“内容与版权说明”，但不得让购买引导遮挡学习内容或伪装成来源结论。普通本地单文件不强制增加购买引导或单独许可文件。

不要把材料机械压缩成同等长度的章节。重要度由学习目标、来源强调、跨来源重复和前置依赖共同决定。

## 视觉选择

- 流程或顺序：`process`，使用 3–7 个短步骤。
- 分类或差异：`comparison`，并列 2–4 组。
- 概念关系：`concept-map`，中心概念加 3–6 个关联节点。
- 来源原图：`image`，使用本地相对路径、alt 和来源图注。
- 没有真正需要图的章节：省略视觉，并用清晰排版、例子或表格承担解释。

遵循认知负荷原则：邻近放置文字与图示、删除无关装饰、复杂内容分段、用信号色强调而非满屏颜色。不得用图片重复大段正文。动画非必要；若添加，必须支持 `prefers-reduced-motion`。

## JSON 约束

参考 `note-schema.example.json`。所有文本都作为纯文本处理，渲染器负责 HTML 转义。`visual.src` 仅允许 `http://`、`https://` 或本地相对路径，禁止 `javascript:`、`data:text/html` 和绝对私有路径。

核心章节的 `source_refs` 至少一项。学习建议或原创练习可没有来源，但要在文字中明确是“建议”而非来源结论。

## 署名、正版引导与权利边界

- 分开表达角色：网页实现者使用 `Code by starline`；书籍、课程或课件作者放在“内容作者/内容来源”中。除非用户明确要求且有依据，不添加学校、机构、联合署名或官方背书。
- 用户明确提供购书 URL 或二维码时，可增加“支持正版”区块。链接使用 HTTPS、在新窗口打开时加 `rel="noopener noreferrer"`；二维码提供描述性 alt 和文字下单方式。无法核验渠道身份时只写“购书/下单”，不写“官方渠道”。
- 来源说明写清材料名称、作者、媒介和使用目的。不要把“仅供学习交流”“如有侵权联系删除”当作授权证明，也不得承诺这些文字已经排除侵权风险。
- 缺少明确许可时遵循最小必要引用：避免公开连续展示完整课件、整页高清扫描或大段原文；优先使用自己的概括、短引用和指向正版来源的链接。权利人要求删除时保留清晰联系渠道和可执行的移除路径。
- 采用 MIT 等代码许可时实行分层授权：许可范围只覆盖原创 HTML/CSS/JavaScript、构建和测试代码；明确排除课件图片、截图、文字摘录、来源派生数据、二维码、商标和其他第三方素材。第三方内容的复用需要另行获得权利人许可。
- 这是一项内容治理检查，不是法律意见。遇到高风险公开传播、商业使用或权属不明素材时，停止扩大分发并建议取得书面授权或专业法律意见。

## 完成检查

- 第一屏能回答“学什么、依据什么、有什么限制”。
- 读者可在 2 分钟内浏览关键收获，在 15–30 分钟内完成主体学习。
- 读者无需先看答案即可完成主动回忆，并能保存或清除本地复述与复习记录。
- 每个视觉都有教学目的、alt 和必要图注。
- 每个关键结论能从来源表跳转或人工定位。
- 代码署名、内容作者和素材权利人没有混写，页面许可范围没有覆盖第三方内容。
- 打印时正文、引用和问题仍可读。
