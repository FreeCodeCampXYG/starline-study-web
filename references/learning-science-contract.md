# 学习方法契约

学习网页的目标不是让用户“读完”，而是帮助用户提取、解释、迁移，并在未来重新提取。方法必须服务具体内容，不做学习法徽章墙。

## 证据优先级

1. **主动回忆 / practice testing：默认必选。** 先呈现问题或情境，参考答案默认折叠。用户应先在脑中、纸上或输入框作答，再展开校准。
2. **分散复习 / distributed practice：默认必选。** 提供可调整的回顾节奏和本地完成状态；不要声称某组固定间隔对所有内容和所有人最优。
3. **自我解释 / teach-back：默认用于概念型内容。** 指定听众与限制，例如“用 60 秒向刚入职的同事讲清楚”；草稿可本地保存，但不得静默上传。
4. **交错练习 / interleaving：只在存在可比较的问题类型时使用。** 不为单一概念硬造随机题库。
5. **二八法则：只作导航。** `核心20%` 表示优先阅读线，不是掌握度、准确率或学习效果证明。

方法依据：Dunlosky 等（2013）把练习测试与分散练习评为高效用，把自我解释与交错练习评为中等效用，并指出后两者的适用证据仍有限：<https://doi.org/10.1177/1529100612453266>。Roediger 与 Karpicke（2006）显示，提取练习在延迟测试中优于重复学习：<https://doi.org/10.1111/j.1467-9280.2006.01693.x>。

## 最小学习闭环

每页根据内容裁剪，但默认按下列顺序：

1. **2 分钟抓核心**：3–7 条可复述的关键判断；给一个唯一主行动。
2. **按需深读**：按任务或依赖顺序组织，不要求从第一页线性滚动。
3. **合上页面回忆**：3–7 道题，问题可先看，答案后展开；至少包含一道边界题。
4. **向具体对象复述**：指定听众、时长和必须包含的三点；避免空泛的“用费曼学习法”。
5. **迁移到真实任务**：要求产出一个可验证的动作、判断或小作品。
6. **安排下次复习**：可用“今天、明天、7 天后、30 天后”作为建议起点，并明确答错则提前、熟练则拉长。

## 交互要求

- 参考答案使用 `details/summary` 或同等可访问控件，默认关闭。
- 复述输入框必须有可见标签、具体提示和保存状态；状态仅保存在 `localStorage` 时要明示。
- 复习勾选不能自动宣称“已掌握”；文案使用“已复习”“已尝试回答”。
- 本地状态必须可重置。没有账号系统时不得制造云同步暗示。
- 键盘可操作，焦点清楚；常用触控目标建议至少 44×44 CSS px。

## 禁止模式

- 固定的遗忘曲线百分比或“看完不忘”承诺。
- 把重读、划重点、收藏或滚动到底当作唯一学习动作。
- 为增加“参与感”而加入无反馈价值的积分、排行榜、连续打卡或烟花动画。
- 参考答案默认展开，或题目与答案紧挨导致无法真正回忆。
- 把方法论文献混进课程或论文自身的来源事实；两类来源必须分开标注。

## 验证与证据边界

自动化可以验证：模块存在、答案默认折叠、本地状态、重置路径、键盘操作、移动端无溢出。自动化不能证明：理解提升、长期保持或真人偏好。没有受控学习者测试时必须写 `missing evidence: learner outcome study`。
